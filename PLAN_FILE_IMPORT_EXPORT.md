# План: сохранение на диск и загрузка обследований из файлов

## Цель

Дать возможность сохранить обследование на диск до отправки, загрузить аудиозапись из файла, а затем восстанавливать обследование из загруженного архива и выполнять новый анализ.

## Текущее состояние

ZIP формируется после анализа через `GET /api/archive/<study_id>`. В `app/task_recordings.py` архив содержит основную запись, калибровку при наличии, аудио попыток и `results.json`. Сохранение полного пакета до анализа и его обратная загрузка в интерфейсе не предусмотрены.

## Этап 1. Общий формат обследования

- Использовать общую структуру данных с локальным кэшем из `PLAN_RECORDING_CACHE.md`.
- Определить версионируемый ZIP: `manifest.json`, основная запись, калибровка при наличии, дополнительные записи при необходимости и результаты анализа при наличии.
- В манифест включить версию формата и протокола, идентификатор локального обследования, параметры записи, границы заданий, попытки, выбранные записи и контрольные суммы файлов.
- Определить минимальный состав персональных данных для экспорта. Системные пути и секреты в архив не включать.
- Согласовать формирование архивов до и после анализа, чтобы оба варианта можно было импортировать.

## Этап 2. Сохранение до отправки

- Добавить кнопки «Скачать запись WAV» и «Сохранить обследование ZIP» после записи и в списке локальных обследований.
- Формировать файлы из локально сохранённых данных без обращения к серверу.
- Пояснить в интерфейсе: WAV содержит аудио, ZIP позволяет восстановить обследование вместе с параметрами и заданиями.
- Использовать стандартное скачивание браузера; выбор каталога зависит от его настроек.

## Этап 3. Загрузка аудиофайлов

- Добавить выбор файла, проверку поддерживаемого формата и размера, декодирование и прослушивание.
- Предусмотреть выбор пациента и задания.
- Для полного обследования требовать корректные границы заданий: произвольная запись без разметки не должна автоматически считаться полным протоколом.
- Если нужен импорт отдельного задания в текущий протокол, явно определять номер задания и создавать новую попытку.
- Сохранять импортированные данные в локальный кэш до отправки.

## Этап 4. Восстановление обследования из ZIP

- Проверять версию манифеста, обязательные файлы, контрольные суммы и согласованность границ заданий с длительностью аудио.
- Ограничить количество файлов, размер архива и общий размер распакованных данных. Отклонять опасные пути и неподдерживаемое содержимое.
- Показать состав обследования, отсутствующие данные и возможность прослушивания до отправки.
- Восстанавливать задания, попытки, выбранные записи, параметры и калибровку.
- Пациента выбирать или подтверждать в текущей учётной записи. Владельца определяет серверная сессия, а не содержимое архива.
- Для нового анализа назначать новый идентификатор запроса; повторные попытки отправить этот импорт используют его же.
- Сохранённые в архиве показатели не должны подменять новый расчёт.
- Добавить совместимость с существующими ZIP с `results.json`, где метаданных достаточно для восстановления; при недостатке данных показывать точную причину и доступный вариант импорта.

## Основные места изменений

- `web/index.html` — действия скачивания, загрузки и предварительного просмотра.
- `web/assets/` — общий формат обследования, сборка и чтение архива.
- `app/task_recordings.py` — согласование серверного ZIP с новым форматом.
- `app/api.py` — проверка переданных данных и использование существующего конвейера анализа.
- `scripts/test_exam_archive.py` и браузерные проверки — совместимость и цикл экспорта/импорта.

## Проверки и критерии готовности

- WAV и ZIP скачиваются до отправки на сервер.
- ZIP, сохранённый до анализа, загружается обратно с сохранением аудио, калибровки и разметки.
- Импортированное обследование проходит текущий конвейер анализа.
- Поддерживаемые старые архивы восстанавливаются; неподдерживаемые получают понятное объяснение.
- Повреждённые архивы, недопустимые границы и превышение лимитов отклоняются.
- Импорт не назначает владельца и пациента без проверки текущих прав.

## Последовательность

Общий формат → локальный кэш и повторная отправка → скачивание WAV/ZIP → загрузка аудиофайлов → восстановление из ZIP.
